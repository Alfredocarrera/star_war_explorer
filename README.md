# 🌌 Star Wars Explorer

¡Bienvenido a **Star Wars Explorer**! Una aplicación web interactiva y dinámica diseñada para explorar la galaxia de Star Wars consumiendo datos en tiempo real desde una API REST (SWAPI). 

El proyecto cuenta con un diseño totalmente *responsive*, animaciones de carga tipo *skeleton*, tarjetas desplegables interactivas y un tema oscuro personalizado inspirado en el universo de la Fuerza.

---

## 🚀 Características Principales

- **📱 Diseño Responsive:** Optimizado para dispositivos móviles, tablets y monitores de escritorio (Grid adaptable).
- **🎨 Tema Star Wars Custom:** Paleta de colores oscura con acentos amarillos y azul sable de luz, además de un cursor personalizado con forma de nave espacial.
- **⚡ Estado de Carga (Skeleton Loaders):** Indicadores visuales animados mientras se obtienen los datos de la API para una mejor experiencia de usuario.
- **🃏 Tarjetas Interactivas:** Vista desplegable tipo "sobre" al hacer clic para ver los detalles de cada película o entidad sin saturar la pantalla.
- **🍔 Menú Hamburguesa:** Navegación fluida que se adapta automáticamente a menú horizontal en computadoras.
- **🔍 Buscador General:** Interfaz lista para filtrar y buscar elementos en la galaxia.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica.
- **CSS3:** Variables CSS (`:root`), Flexbox, CSS Grid, Media Queries y animaciones avanzadas (`@keyframes`).
- **JavaScript :** Manipulación del DOM, eventos e integración de API.
- **Git & GitHub:** Control de versiones.
